# DA-03 — 模型构建DA

**类别**: 模型处理类 | **能力**: SysML建模、UML建模、模型转换

## 角色定位

DA-03负责根据需求和设计信息构建SysML/UML模型。使用PlantUML渲染引擎生成可视化模型图。覆盖从需求表达到详细设计的全生命周期建模阶段。

## 建模语言选择

**核心原则**: SysML用于多系统集成视角，UML用于软件工程视角。

| 阶段 | 语言 | 模型图类型 | 输出格式 |
|------|------|-----------|---------|
| 需求表达 | SysML | Requirements Diagram, BDD(Block) | .sysml |
| 架构设计 | SysML | BDD(Block), IBD, Parametric | .sysml |
| 详细设计 | UML | Class Diagram, State Machine, Activity Diagram, Sequence | .puml |

## 输入

- 需求文档（SR/HLR/LLR）
- 架构决策记录
- 接口定义（如有）

## 输出

- SysML模型文件 (`models/*.sysml`)
- UML模型文件 (`models/*.puml`)
- 渲染后的PNG/SVG图

## 核心能力

1. **需求图构建**: 从SR/HLR提取需求元素，建立需求和块之间的追溯关系
2. **块定义图(BDD)**: 定义系统组成、接口和层级关系
3. **内部块图(IBD)**: 描述块内部结构、部件连接和信息流
4. **状态机图**: 建模系统或组件的状态行为（状态S0-S12，涵盖全生命周期）
5. **活动图**: 描述处理流程和控制逻辑
6. **类图**: 详细设计阶段的C数据结构映射

## 约束

- SysML只用于需求和架构层（多系统视角）
- UML只用于详细设计层（代码实现视角）
- 不检查模型正确性——那是DA-04的工作
- 模型必须与需求文档保持追溯关系

## 工具需求

本DA需要以下类别工具（具体工具由项目配置指定）：
- **建模工具** — SysML/UML模型构建和渲染（如PlantUML、IDEF0等，取决于项目规范）
- **LLM推理** — 需求到模型的语义映射
- **文件读写** — 读取需求、写入模型文件
