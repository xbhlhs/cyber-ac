## 0. 文档目的与范围

本文档从 SR-1 需求族（SR → HLR → LLR）中识别**测试场景（Test Scenarios）**，供 DA-08（test-case）据此生成测试用例、DA-09（test-procedure）据此编写测试规程。

**边界声明**：
- 本文档**不生成测试用例**（DA-08 职责）——场景只描述"行为路径 + 触发条件 + 预期行为"，不包含具体输入刺激值、判定步骤与通过/失败判据的逐条用例化。
- 本文档**不编写测试规程**（DA-09 职责）——不含目标环境操作步骤、数据装载、结果记录格式。
- 场景粒度：一个场景对应一个**可独立测试的行为路径**。
- 场景全部由 SR/HLR/LLR 原文语义派生，**不新增需求、不补充工程假设**；SR/HLR/LLR 未定义之处一律继承未决项（AMB-01~07、LLR-AMB-08~11），**只记录不消解**。

## 1. 需求基线摘要

| 层级 | 条目 | 语义要点 |
|------|------|---------|
| SR-1 §1a/§1b/§1c | LA 输出条件 | 该周期 LA 数据有效 **且** LA 与 EQC.LA 对比一致 → 输出；否则不输出 |
| SR-1 §2a/§2b/§2c | LB 输出条件 | 该周期 LB 数据有效 **且** LB 与 EQC.LB 对比一致 → 输出；否则不输出 |
| SR-1 §3 | LC 输出条件 | 生成的 LC 与 EQB.LC 对比一致 → 输出；否则不输出（**无有效性检查**，设计意图） |
| HLR-LA-001~003 / HLR-LB-001~003 | LA/LB 有效性评估、一致性比较、输出抑制 | 有效 ∧ 一致 → 输出；任一不满足 → 抑制 |
| HLR-LC-001~003 | LC 一致性比较、输出抑制、无有效性检查（不对称性正式记录） | 一致 → 输出；不一致 → 抑制 |
| HLR-COM-001 | 周期条件输出通用行为 | 每周期条件评估：满足→输出一次；不满足→抑制；三数据对象独立、逐周期重复 |
| LLR-LA-001~003 / LLR-LB-001~003 | 周期布尔标志（`*_valid`、`*_match`）与双条件门控 | 门控逻辑：valid ∧ match |
| LLR-LC-001/002 | LC 仅一致性比较与单判据门控（无 `lc_valid`） | 门控逻辑：match 单判据 |
| LLR-COM-001/002/003 | 固定周期调度（编译期常量）、三通道独立、LC 不对称性保持 | 无动态内存；周期常量参数化 |

## 2. 目标映射声明（DO-178C，DAL D）

本文档识别的测试场景按 DO-178C 表 A-6（DAL D 适用）映射如下，供测试阶段（DA-08/09/10）落实：

| 目标 | 名称 | 支持的场景类别 | 本文档对应场景 |
|------|------|---------------|----------------|
| **A6-1** | Executable Object Code complies with HLR（正常范围） | 正常路径（Happy Path）、正常范围内的边界条件 | TS-01、TS-04、TS-07、TS-09（正常侧）、TS-13（一致侧）、TS-14（一致侧）等 |
| **A6-2** | Executable Object Code is robust with HLR（鲁棒性） | 异常/错误路径、边界外行为、抑制路径 | TS-02、TS-03、TS-05、TS-06、TS-08、TS-10、TS-12、TS-15、TS-16 等 |
| **A6-5** | Executable Object Code is compatible with target computer | 目标环境（Cortex-M4）相关行为路径 | TS-19、TS-20、TS-21 |

说明：A6-1 与 A6-2 场景的区别在于输入处于需求定义的正常范围（A6-1）还是异常/鲁棒性范围（A6-2）；由于 SR 未定义判据（AMB-02/AMB-03/AMB-06），具体刺激的"正常/异常"边界划分依赖未决项消解，本阶段以逻辑路径划分（输出路径→A6-1 相关，抑制/缺失/连续失败路径→A6-2 相关）。A6-5 场景关注目标环境相关行为（无动态内存、编译期周期常量、接口时序），最终执行环境由测试阶段确定。

## 3. 场景清单

场景编号沿用 DA-01 初始场景骨架（TS-01~TS-10，语义对齐并更新追溯链），并扩展 TS-11~TS-21。类别缩写：**HP**=正常路径，**BD**=边界条件，**ER**=异常/错误路径，**CM**=组合场景，**TE**=目标环境。

### 3.1 正常路径（Happy Path，支持 A6-1）

#### TS-01 LA 正常输出（有效 且 一致）
- **描述**：EQA 每周期对待输出 LA 执行有效性评估并通过，且 LA 与 EQC 发送的 LA（EQC.LA）一致性比较一致，该周期输出 LA 一次。
- **触发条件**：`la_valid` = 真（有效性检查通过）且 `la_match` = 真（LA == EQC.LA）。
- **预期行为**：通过 LA 输出接口输出本周期 LA 数据，每周期恰好一次；逐周期重复。
- **需求追溯**：SR-1 §1a/§1b/§1c；HLR-LA-001、HLR-LA-002、HLR-LA-003（肯定侧）；LLR-LA-001、LLR-LA-002、LLR-LA-003；原子规则 AR-01、AR-02、AR-10。
- **目标映射**：A6-1。
- **关联未决项**：AMB-01（周期语义）、AMB-02（有效性判据）、AMB-03（比较语义）、AMB-06（类型/格式）、AMB-07（数据来源）、LLR-AMB-11（数据获取接口）——预期行为的可实例化依赖其消解。

#### TS-04 LB 正常输出（有效 且 一致）
- **描述**：EQA 每周期对待输出 LB 执行有效性评估并通过，且 LB 与 EQC 发送的 LB（EQC.LB）一致性比较一致，该周期输出 LB 一次。
- **触发条件**：`lb_valid` = 真 且 `lb_match` = 真（LB == EQC.LB）。
- **预期行为**：通过 LB 输出接口输出本周期 LB 数据，每周期恰好一次；逐周期重复。与 TS-01 对称。
- **需求追溯**：SR-1 §2a/§2b/§2c；HLR-LB-001、HLR-LB-002、HLR-LB-003（肯定侧）；LLR-LB-001、LLR-LB-002、LLR-LB-003；AR-04、AR-05、AR-10。
- **目标映射**：A6-1。
- **关联未决项**：AMB-01、AMB-02、AMB-03、AMB-06、AMB-07、LLR-AMB-11。

#### TS-07 LC 正常输出（一致，无有效性检查）
- **描述**：EQA 每周期将生成的 LC 与 EQB 发送的 LC（EQB.LC）一致性比较一致，该周期输出 LC 一次。LC 路径**不执行有效性检查**（HLR-LC-003 / LLR-COM-003：LC 无有效性概念，每一电位都是有效信号）。
- **触发条件**：`lc_match` = 真（LC == EQB.LC）。无 `lc_valid` 类条件。
- **预期行为**：通过 LC 输出接口输出本周期 LC 数据，每周期恰好一次；逐周期重复。测试设计**不得引入"LC 无效"输入场景**（LLR-LC-001/002、LLR-COM-003）。
- **需求追溯**：SR-1 §3；HLR-LC-001、HLR-LC-002（肯定侧）、HLR-LC-003；LLR-LC-001、LLR-LC-002、LLR-COM-003；AR-07、AR-08、AR-10。
- **目标映射**：A6-1。
- **关联未决项**：AMB-01、AMB-03、AMB-04（不对称性设计意图，已确认）、AMB-06、LLR-AMB-08、LLR-AMB-11。

### 3.2 边界条件（Boundary Conditions，支持 A6-1/A6-2）

#### TS-09 多周期序列（周期边界与逐周期独立）
- **描述**：在连续多个周期内交替改变条件状态（满足/不满足），验证 EQA 逐周期独立评估，不跨周期耦合。
- **触发条件**：连续 ≥ 2 个周期，各周期条件组合按需设置（如：满足→不满足→满足）。
- **预期行为**：每个周期独立判定：条件满足周期输出一次，条件不满足周期抑制；条件恢复后重新输出。抑制是否仅限当周期、周期边界/触发/输出时刻依赖 AMB-01、AMB-05 消解（本场景先验证"逐周期独立"行为模式本身）。
- **需求追溯**：SR-1 §1/§2/§3（行为模式）；HLR-COM-001；LLR-COM-001、LLR-COM-002；AR-10。
- **目标映射**：A6-1（正常周期行为）、A6-2（抑制侧周期行为）。
- **关联未决项**：AMB-01、AMB-05、LLR-AMB-09（周期常量数值）。

#### TS-12 有效性判据边界（LA/LB）
- **描述**：LA/LB 数据处于有效性判据的边界位置（如恰好等于判据阈值/临界值）时，有效性评估应给出确定且一致的结果。
- **触发条件**：LA/LB 输入数据恰好处于有效性判据边界（判据本身未定义，见 AMB-02）。
- **预期行为**：**判定挂起**——有效/无效的边界归属无法在判据消解前确定；本场景记录"必须覆盖判据边界值"的测试关注点，具体预期行为依赖 AMB-02 消解后补充。当前阶段不得假设边界归属。
- **需求追溯**：SR-1 §1a/§2a；HLR-LA-001、HLR-LB-001；LLR-LA-001、LLR-LB-001；AR-01、AR-04。
- **目标映射**：A6-2（边界外鲁棒性关注点）。
- **关联未决项**：AMB-02、AMB-06、LLR-AMB-08（结构定义决定判据承载字段）。

#### TS-13 一致性比较最小差异边界
- **描述**：比较数据对仅在**单个字段（或单个比特）**上不同、其余完全相同，验证一致性比较能捕获最小差异并产生"不一致"判定。
- **触发条件**：LA/LB/LC 与对应 EQC/EQB 数据仅在一个字段（或一个比特）上不同。
- **预期行为**：比较判定为"不一致"→ 对应通道抑制输出（LA/LB 侧还需有效性通过才有抑制语义，见 TS-02/05/08）。比较语义（逐位相等/容差/粒度）未定义，**具体"最小差异"的粒度依赖 AMB-03 消解**；本场景先锁定"最小可辨识差异必须被判定为不一致"这一行为要求。
- **需求追溯**：SR-1 §1b/§2b/§3；HLR-LA-002、HLR-LB-002、HLR-LC-001；LLR-LA-002、LLR-LB-002、LLR-LC-001；AR-02、AR-05、AR-07。
- **目标映射**：A6-1（一致侧边界）、A6-2（不一致侧边界）。
- **关联未决项**：AMB-03、AMB-06、LLR-AMB-08（结构定义决定"字段"粒度）。

#### TS-14 数据极值边界
- **描述**：LA/LB/LC 及其比较对象取数据类型范围内的**最大值/最小值（极值）**参与比较，验证比较与输出在极值输入下行为正常。
- **触发条件**：本地数据与 EQC/EQB 数据同时取类型极值（一致极值）或仅一侧取极值（极值不一致）。
- **预期行为**：一致极值 → 输出；极值不一致 → 抑制。数据类型、格式、取值范围未定义，**具体极值依赖 AMB-06、LLR-AMB-08 消解**；本场景记录"必须覆盖极值输入"的关注点。
- **需求追溯**：SR-1 §1b/§2b/§3；HLR-LA-002、HLR-LB-002、HLR-LC-001；LLR-LA-002、LLR-LB-002、LLR-LC-001。
- **目标映射**：A6-1（极值正常路径）、A6-2（极值异常路径）。
- **关联未决项**：AMB-03、AMB-06、LLR-AMB-08。

### 3.3 异常/错误路径（Error/Exception Paths，支持 A6-2）

#### TS-02 LA 一致性失败 → 抑制
- **描述**：LA 有效性检查通过，但 LA 与 EQC.LA 一致性比较不一致，该周期抑制 LA 输出。
- **触发条件**：`la_valid` = 真 且 `la_match` = 假。
- **预期行为**：不输出 LA（不执行 LA 输出动作）。抑制期间下游接口行为（保持旧值/发送抑制标识/静默）未定义，依赖 AMB-05、LLR-AMB-10 消解。
- **需求追溯**：SR-1 §1b/§1c；HLR-LA-002（否定侧）、HLR-LA-003；LLR-LA-002、LLR-LA-003；AR-02、AR-03。
- **目标映射**：A6-2。
- **关联未决项**：AMB-02、AMB-03、AMB-05、LLR-AMB-10。

#### TS-03 LA 无效 → 抑制（AND 语义必要条件）
- **描述**：LA 有效性检查不通过，**无论一致性比较结果如何**，该周期均抑制 LA 输出（验证"有效性"为 LA 输出的必要条件，AND 语义否定侧）。
- **触发条件**：`la_valid` = 假（`la_match` 任意：真或假）。
- **预期行为**：不输出 LA。覆盖两个子情形：无效+一致、无效+不一致 → 均抑制。
- **需求追溯**：SR-1 §1a/§1c；HLR-LA-001（否定侧）、HLR-LA-003；LLR-LA-001、LLR-LA-003；AR-01、AR-03。
- **目标映射**：A6-2。
- **关联未决项**：AMB-02、AMB-03、AMB-05、LLR-AMB-10。

#### TS-05 LB 一致性失败 → 抑制
- **描述**：LB 有效性检查通过，但 LB 与 EQC.LB 一致性比较不一致，该周期抑制 LB 输出。与 TS-02 对称。
- **触发条件**：`lb_valid` = 真 且 `lb_match` = 假。
- **预期行为**：不输出 LB。抑制期间下游接口行为依赖 AMB-05、LLR-AMB-10 消解。
- **需求追溯**：SR-1 §2b/§2c；HLR-LB-002（否定侧）、HLR-LB-003；LLR-LB-002、LLR-LB-003；AR-05、AR-06。
- **目标映射**：A6-2。
- **关联未决项**：AMB-02、AMB-03、AMB-05、LLR-AMB-10。

#### TS-06 LB 无效 → 抑制（AND 语义必要条件）
- **描述**：LB 有效性检查不通过，无论一致性结果如何，该周期均抑制 LB 输出。与 TS-03 对称。
- **触发条件**：`lb_valid` = 假（`lb_match` 任意）。
- **预期行为**：不输出 LB。覆盖子情形：无效+一致、无效+不一致 → 均抑制。
- **需求追溯**：SR-1 §2a/§2c；HLR-LB-001（否定侧）、HLR-LB-003；LLR-LB-001、LLR-LB-003；AR-04、AR-06。
- **目标映射**：A6-2。
- **关联未决项**：AMB-02、AMB-03、AMB-05、LLR-AMB-10。

#### TS-08 LC 一致性失败 → 抑制（单判据否定侧）
- **描述**：生成的 LC 与 EQB.LC 一致性比较不一致，该周期抑制 LC 输出。LC 输出判定**仅依赖一致性单一判据**，无有效性分支。
- **触发条件**：`lc_match` = 假。
- **预期行为**：不输出 LC。不得将"LC 无效"作为触发条件引入（无 `lc_valid` 概念，HLR-LC-003 / LLR-COM-003）。抑制期间下游接口行为依赖 AMB-05、LLR-AMB-10 消解。
- **需求追溯**：SR-1 §3；HLR-LC-002、HLR-LC-003；LLR-LC-002、LLR-COM-003；AR-07、AR-09。
- **目标映射**：A6-2。
- **关联未决项**：AMB-03、AMB-04（设计意图已确认）、AMB-05、LLR-AMB-10。

#### TS-10 EQC/EQB 比较数据缺失（期望行为未定义，暂挂起）
- **描述**：某周期 EQC 未发送 LA/LB 比较数据或 EQB 未发送 LC 比较数据（比较对象缺失/未就绪），EQA 应如何表现。
- **触发条件**：EQC.LA / EQC.LB / EQB.LC 数据缺失或不可用。
- **预期行为**：**未定义**——SR/HLR/LLR 均未规定数据缺失时比较的输入取值（如按无效处理/按不一致处理/保持上周期）与输出行为。本场景**挂起**：期望行为依赖 AMB-05、AMB-07、LLR-AMB-11 消解后补全；消解前不得假设（如不得假设"缺失即不一致→抑制"）。
- **需求追溯**：SR-1 §1b/§2b/§3（比较对象来源条款）；HLR-LA-002、HLR-LB-002、HLR-LC-001；LLR-LA-002、LLR-LB-002、LLR-LC-001；AR-02、AR-05、AR-07。
- **目标映射**：A6-2（鲁棒性关注点，待判据消解后落实）。
- **关联未决项**：AMB-05、AMB-07、LLR-AMB-11。

#### TS-15 连续多周期抑制（连续失败行为）
- **描述**：多个连续周期条件均不满足（如连续不一致/连续无效），验证 EQA 持续抑制输出且无未定义行为（如错误指示、状态变化、输出抖动）。
- **触发条件**：连续 ≥ 2 个周期各通道条件不满足（如连续不一致）。
- **预期行为**：每个周期均抑制输出，行为稳定一致。错误指示/故障处理、连续失败行为、抑制是否仅限当周期均未定义，依赖 AMB-05 消解；消解前只验证"逐周期持续抑制且不产生需求未定义之外的行为"。
- **需求追溯**：SR-1 §1c/§2c/§3（抑制条款）；HLR-LA-003、HLR-LB-003、HLR-LC-002、HLR-COM-001；LLR-LA-003、LLR-LB-003、LLR-LC-002、LLR-COM-001；AR-03、AR-06、AR-09、AR-10。
- **目标映射**：A6-2。
- **关联未决项**：AMB-01、AMB-05、LLR-AMB-10。

#### TS-16 LA/LB 双条件同时不满足（无效 且 不一致）
- **描述**：LA/LB 有效性检查不通过**且**一致性比较不一致同时发生，验证双条件否定侧组合仍抑制输出（与 TS-03/06 的"无效+一致"子情形区分）。
- **触发条件**：`la_valid` = 假 且 `la_match` = 假（LB 同理）。
- **预期行为**：不输出 LA/LB。与 TS-03/06 共同构成 LA/LB 门控否定侧完整覆盖：无效+一致、有效+不一致（TS-02/05）、无效+不一致（本场景）。
- **需求追溯**：SR-1 §1c/§2c；HLR-LA-003、HLR-LB-003；LLR-LA-003、LLR-LB-003；AR-03、AR-06。
- **目标映射**：A6-2。
- **关联未决项**：AMB-02、AMB-03、AMB-05、LLR-AMB-10。

### 3.4 组合场景（Combination Cases，支持 A6-1/A6-2）

#### TS-11 三通道同周期全输出
- **描述**：同一周期内 LA、LB、LC 三通道条件全部满足，验证三通道各自独立输出一次，互不干扰。
- **触发条件**：`la_valid`∧`la_match`、`lb_valid`∧`lb_match`、`lc_match` 同周期全部为真。
- **预期行为**：LA、LB、LC 各自通过对应输出接口输出一次；三通道独立评估（LLR-COM-002），无顺序依赖、无相互影响。
- **需求追溯**：SR-1 §1/§2/§3；HLR-COM-001；LLR-COM-001、LLR-COM-002；AR-10。
- **目标映射**：A6-1。
- **关联未决项**：AMB-01、AMB-07、LLR-AMB-11。

#### TS-17 同周期三通道混合条件（输出/抑制并存）
- **描述**：同一周期内三通道条件状态不同（如 LA 满足、LB 不满足、LC 满足），验证各通道独立判定，抑制通道不影响输出通道。
- **触发条件**：三通道条件组合取混合态（如 `la`：有效+一致；`lb`：无效或`lb_match`=假；`lc`：`lc_match`=真）。
- **预期行为**：满足通道输出一次，不满足通道抑制；通道间零耦合（任一通道的评估/判定结果不影响其他通道）。
- **需求追溯**：SR-1 §1/§2/§3；HLR-COM-001；LLR-COM-002；AR-10。
- **目标映射**：A6-1（输出侧）、A6-2（抑制侧）。
- **关联未决项**：AMB-01、AMB-05、AMB-07、LLR-AMB-10、LLR-AMB-11。

#### TS-18 跨周期恢复（N 周期抑制 → N+1 周期输出）
- **描述**：周期 N 条件不满足（抑制），周期 N+1 条件恢复满足，验证 EQA 在 N+1 周期恢复正常输出，不被上一周期抑制状态锁存。
- **触发条件**：周期 N 抑制（如不一致），周期 N+1 恢复一致（LA/LB 侧恢复有效+一致）。
- **预期行为**：周期 N 不输出，周期 N+1 正常输出一次；逐周期独立评估，无跨周期状态泄漏。抑制是否仅限当周期依赖 AMB-05 消解后最终确认（若抑制语义定义为跨周期持续，则本场景预期随之调整——当前按"每周期独立"的 HLR-COM-001 语义记录）。
- **需求追溯**：SR-1 §1/§2/§3；HLR-COM-001；LLR-COM-001、LLR-COM-002；AR-10。
- **目标映射**：A6-1、A6-2。
- **关联未决项**：AMB-01、AMB-05、LLR-AMB-09、LLR-AMB-10。

### 3.5 目标环境场景（Target Computer，支持 A6-5）

#### TS-19 一致性比较实现与目标环境兼容（零动态内存、memcmp 使用约束）
- **描述**：验证一致性比较实现（字段逐一相等比较或 memcmp）在目标环境（Cortex-M4）上可正确运行：不得使用动态内存分配（禁止 malloc/realloc/calloc）；memcmp 仅当两侧数据结构大小可静态确定且无填充歧义时方可使用。
- **触发条件**：在目标环境上执行含一致性比较路径的处理周期（一致与不一致注入均可）。
- **预期行为**：比较路径在目标环境上无动态内存调用（静态确认 + 运行验证）；使用 memcmp 时其适用前提（结构大小静态确定、无填充歧义）成立；比较结果与宿主机行为一致。数据结构定义（LLR-AMB-08）消解前，memcmp 适用性的最终确认挂起。
- **需求追溯**：SR-1 §1b/§2b/§3；HLR-LA-002、HLR-LB-002、HLR-LC-001；LLR-LA-002、LLR-LB-002、LLR-LC-001（比较实现约束）。
- **目标映射**：A6-5。
- **关联未决项**：AMB-03、AMB-06、LLR-AMB-08。

#### TS-20 固定周期调度在目标环境上的执行
- **描述**：验证固定周期处理流水线在目标环境上按编译期常量参数化周期（暂记 `PROCESS_CYCLE_MS`）重复执行，实现不依赖运行时动态配置周期。
- **触发条件**：在目标环境上运行多个连续处理周期，观察周期调度与各通道输出/抑制行为。
- **预期行为**：每周期完成 LA/LB/LC 三通道处理与输出判定并逐周期重复；周期时长由编译期常量确定，无运行时动态配置；周期时长数值（LLR-AMB-09）消解前不验证具体时间值，仅验证"固定周期调度机制"存在且稳定。
- **需求追溯**：SR-1 §1/§2/§3（行为模式）；HLR-COM-001；LLR-COM-001；AR-10。
- **目标映射**：A6-5。
- **关联未决项**：AMB-01、LLR-AMB-09。

#### TS-21 目标环境上 EQC/EQB 数据获取接口可用性与时序
- **描述**：验证 EQA 在目标环境上按周期获取待输出数据与 EQC/EQB 比较数据的接口可用性与时序行为（周期内数据可用性、存储与传递方式）。
- **触发条件**：在目标环境上运行处理周期，EQC/EQB 数据在周期内到达/未到达的时序情形。
- **预期行为**：数据获取接口在目标环境上按周期正常工作；接口机制、存储传递方式、周期内可用性未定义，**具体预期依赖 AMB-07、LLR-AMB-11 消解**；本场景记录"目标环境上接口时序"的验证关注点（与 TS-10 的缺失数据行为相关联）。
- **需求追溯**：SR-1 §1b/§2b/§3（比较数据来源）；HLR-LA-002、HLR-LB-002、HLR-LC-001；LLR-LA-002、LLR-LB-002、LLR-LC-001、LLR-COM-002；AR-02、AR-05、AR-07。
- **目标映射**：A6-5。
- **关联未决项**：AMB-01、AMB-07、LLR-AMB-11。
