## 1. 文档目的与范围

本文档将 DA-07 测试场景文档（`evidence/test_scenarios.md`，21 个场景）**逐场景实例化为可执行的测试用例**，供 DA-09（test-procedure）编写目标环境执行规程、DA-10（test-exec）执行。

**边界声明**（与 DA-08 AGENT.md 契约一致）：
- 本文档**不分析场景**（DA-07 职责），场景语义全部沿用场景文档；
- 本文档**不编写测试规程**（DA-09 职责），不包含目标环境操作细节、数据装载、结果记录格式；
- 每个用例标注来源场景 ID 与需求追溯链（SR/HLR/LLR），可独立执行，不依赖其他用例副作用；
- 用例预期输出**严格从需求原文推导**（SR §1/§2/§3 与 HLR/LLR 语义），不发明语义；SR/HLR/LLR 未定义之处（AMB-01~07、LLR-AMB-08~11）一律只记录不消解，对应用例标记为挂起或在该用例内显式声明"不判定"。

- **场景基线**：`evidence/test_scenarios.md`（DA-07，TS-01~TS-21）。
- **需求基线**：`sr.md`（SR-1，§1a/§1b/§1c、§2a/§2b/§2c、§3、关键观察）、`hlr.md`（HLR-LA-001~003 / HLR-LB-001~003 / HLR-LC-001~003 / HLR-COM-001，共 10 条）、`llr.md`（LLR-LA-001~003 / LLR-LB-001~003 / LLR-LC-001~002 / LLR-COM-001~003，共 11 条）。

## 4. DO-178C 目标映射与编码约束

本测试用例文档按 **DO-178C 表 A-6（§6.4 软件测试，DAL D 适用）** 映射测试目标。**旧版错误引用的 §6.3.1（表 A-3，A3-* HLR 验证目标）与本文档无关**。

### 4.1 A6-1 — Executable Object Code complies with HLR（正常范围，§6.4.a）

验证可执行目标代码在**正常输入范围**内的行为符合 HLR：条件满足（LA/LB：有效 且 一致；LC：一致）→ 每周期输出一次；多周期逐周期重复；三通道独立全输出；一致性比较一致侧（零差异/极值一致）判定正确。

- 对应场景：TS-01、TS-04、TS-07（正常路径）；TS-09/TS-11/TS-17/TS-18（输出侧）；TS-13/TS-14（一致侧边界）；TS-19/TS-20/TS-21（目标环境一致路径）。
- 用例集：第 5.1 节全部 + 第 5.2/5.4 节中标 A6-1 的用例。

### 4.2 A6-2 — Executable Object Code is robust with HLR（鲁棒性，§6.4.b）

验证可执行目标代码在**异常/鲁棒性输入**下的行为符合 HLR：LA/LB 门控否定侧全覆盖（有效+不一致、无效+一致、无效+不一致）、LC 单判据否定侧、连续多周期抑制、抑制后跨周期恢复、比较最小差异与极值不一致被判定为不一致。

- 对应场景：TS-02、TS-03、TS-05、TS-06、TS-08（抑制路径）；TS-09/TS-15/TS-16/TS-17（抑制侧）；TS-10、TS-12（**挂起**，判据未定义）；TS-13/TS-14（不一致侧）；TS-19/TS-21（目标环境抑制路径/时序变异）。
- 用例集：第 5.3 节全部 + 第 5.2/5.4 节中标 A6-2 的用例。
- **诚实性声明**：TS-10（比较数据缺失）与 TS-12（有效性判据边界）的预期行为未定义，其用例（TC-10-001、TC-12-001/002、TC-21-002）标记为**挂起/待判据消解**，不虚构预期输出；消解前 A6-2 对这两类行为路径的验证为"已记录关注点、未执行判定"状态。

### 4.3 A6-5 — Executable Object Code is compatible with target computer（目标环境兼容性，§6.4.e）

验证可执行目标代码在**目标计算机（Cortex-M4 / arm-none-eabi-gcc）**上的兼容性：一致性比较路径零动态内存（禁止 malloc/realloc/calloc）静态确认与运行验证；memcmp 使用前提（结构大小静态可确定、无填充歧义）审查；固定周期调度由编译期常量参数化（无运行时动态配置）；EQC/EQB 数据获取接口在目标环境上的按周期可用性与时序。

- 对应场景：TS-19、TS-20、TS-21（目标环境场景）。
- 用例集：第 5.4 节全部。
