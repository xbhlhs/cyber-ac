## LLR-LA-001 LA 每周期有效性评估

| 属性 | 内容 |
|------|------|
| ID | LLR-LA-001 |
| Source | HLR-LA-001 |
| Description | EQA 应在每个处理周期内对待输出的 LA 数据执行有效性评估，并将评估结果保存为周期内布尔标志（暂记 `la_valid`）：评估通过置真，不通过置假。有效性判定准则（范围、校验、新鲜度等）SR/HLR 未定义（AMB-02），本条仅要求「存在有效性评估且其结果作为 LA 输出条件之一」，不定义判据。 |
| Rationale | HLR-LA-001 规定 LA 输出的前提条件之一为「该周期待输出的 LA 数据有效」；LLR 将有效性评估落实为周期内布尔标志，供输出门控（LLR-LA-003）使用。判据缺失属 AMB-02，只记录不消解。 |
| Verifiability | 分析 / 测试：验证每个周期均执行有效性评估且 `la_valid` 随评估结果更新；判定正确性的具体验证依赖 AMB-02 消解。 |
| 关联未决项 | AMB-01（周期语义）、AMB-02（有效性定义）、AMB-06（类型/格式）、AMB-07（数据来源）、LLR-AMB-11（数据获取接口） |

## LLR-LA-002 LA 一致性比较

| 属性 | 内容 |
|------|------|
| ID | LLR-LA-002 |
| Source | HLR-LA-002 |
| Description | EQA 应在每个处理周期内将待输出的 LA 数据与 EQC 发送的 LA 数据（EQC.LA）进行一致性比较，比较结果保存为周期内布尔标志（暂记 `la_match`）：一致置真，不一致置假。比较实现约束：采用字段逐一相等比较，或 memcmp（仅当两侧数据结构大小可静态确定且无填充歧义时），**不得使用动态内存分配（禁止 malloc/realloc/calloc）**。比较语义（逐位相等/容差/粒度/编码域）未定义（AMB-03），本条不定义比较方法。 |
| Rationale | HLR-LA-002 规定「LA 与 EQC.LA 对比一致」为 LA 输出的另一前提条件；LLR 落实比较动作与结果标志。零动态内存与 C11/GCC 约束来自项目配置；比较方法细节（AMB-03）不补充。 |
| Verifiability | 测试：注入一致/不一致 LA 数据对，验证 `la_match` 置位正确（具体刺激依赖 AMB-03/AMB-06 消解）；静态分析：确认比较路径无 malloc/realloc/calloc。 |
| 关联未决项 | AMB-01、AMB-03（比较方法）、AMB-06、AMB-07、LLR-AMB-08（数据结构定义）、LLR-AMB-11 |

## LLR-LA-003 LA 输出门控（有效性 且 一致性）

| 属性 | 内容 |
|------|------|
| ID | LLR-LA-003 |
| Source | HLR-LA-003 |
| Description | EQA 仅当 `la_valid` 与 `la_match` **同时为真**（有效性通过 且 一致性一致）时，才通过 LA 输出接口输出本周期 LA 数据；任一不满足（有效性不通过 或 一致性不一致）时，抑制本周期 LA 输出（不执行输出动作）。抑制期间下游接口行为（保持旧值/发送抑制标识/静默）未定义（AMB-05、LLR-AMB-10），本条不定义。 |
| Rationale | HLR-LA-003 为「有效性 且 一致性」AND 语义的否定侧（与 HLR-LA-001、HLR-LA-002 共同构成完整输出条件）；LLR 落实为双条件门控。 |
| Verifiability | 测试：覆盖四类场景——有效+一致→输出；有效+不一致→抑制；无效+一致→抑制；无效+不一致→抑制（具体输入刺激依赖 AMB-02/AMB-03 消解）。 |
| 关联未决项 | AMB-02、AMB-03、AMB-05（错误处理）、LLR-AMB-10（抑制接口行为） |
