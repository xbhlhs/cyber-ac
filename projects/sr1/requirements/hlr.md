## HLR-LA-001 LA 周期输出与有效性检查

| 属性 | 内容 |
|------|------|
| ID | HLR-LA-001 |
| Source | SR-1 §1a |
| Description | EQA 应每个周期评估 LA 数据的输出条件；LA 输出的前提条件之一是该周期待输出的 LA 数据有效。 |
| Rationale | SR-1 §1a 规定 LA 输出条件为「该周期输出的 LA 数据有效」，对应 DA-01 原子规则 AR-01。有效性判定准则（范围、校验、新鲜度等）SR 未定义（AMB-02），本条仅保留 SR 原语义，不补充判据。 |
| Verifiability | 测试 / 分析：验证 EQA 在输出 LA 前执行有效性评估这一行为的存在性；有效/无效判定方式的具体验证依赖 AMB-02 消解。 |
| 关联未决项 | AMB-01（周期语义）、AMB-02（有效性定义）、AMB-06（类型/格式）、AMB-07（数据来源） |

## HLR-LA-003 LA 输出抑制

| 属性 | 内容 |
|------|------|
| ID | HLR-LA-003 |
| Source | SR-1 §1c |
| Description | 当 LA 有效性检查不通过或 LA 一致性比较不一致（任一不满足）时，EQA 应抑制该周期 LA 输出（不输出 LA）。 |
| Rationale | SR-1 §1c「否则不输出LA数据」与 R-05（条件不满足时禁止输出），对应原子规则 AR-03。与 HLR-LA-001、HLR-LA-002 构成「有效性 且 一致性」AND 语义的否定侧。抑制的持续范围（是否仅限当周期）及错误处理行为 SR 未定义（AMB-05），本条不补充。 |
| Verifiability | 测试：覆盖三类抑制场景（有效+不一致→不输出；无效+一致→不输出；无效+不一致→不输出）；具体输入刺激依赖 AMB-02/AMB-03 消解。 |
| 关联未决项 | AMB-02、AMB-03、AMB-05（错误处理） |

## HLR-LC-003 LC 无有效性检查（不对称性显式声明）

| 属性 | 内容 |
|------|------|
| ID | HLR-LC-003 |
| Source | SR-1 §3（SR-1 关键观察） |
| Description | LC 输出不要求有效性检查：EQA 对 LC 仅执行一致性比较，不执行与 LA/LB 类似的有效性检查。该不对称性（LA/LB 含「有效性检查+一致性比较」，LC 仅含「一致性比较」）为 SR-1 关键观察所述、经人工评审确认的**设计意图**，须在后续设计/实现中显式保留，不得归一化为 LA/LB 行为，亦不得擅自「补全」LC 有效性检查。 |
| Rationale | SR-1 关键观察：「LC信号不存在有效性概念，每一个电位都是有效信号」。对应原子规则 AR-08 与 DA-01 未决项 AMB-04（要求在 HLR 中显式保留该不对称并形成正式记录）。本条即为该正式记录。 |
| Verifiability | 审查：HLR/LLR/代码评审确认 LC 路径无有效性检查、无有效性分支；测试：LC 测试设计不得引入「LC 无效」输入场景。 |
| 关联未决项 | AMB-04（LC 有效性不对称；设计意图已确认，作为未决项继续上报以完成正式记录） |

## HLR-COM-001 周期条件输出通用行为

| 属性 | 内容 |
|------|------|
| ID | HLR-COM-001 |
| Source | SR-1 §1 / §2 / §3（全局） |
| Description | EQA 对 LA、LB、LC 的输出行为均为每周期条件评估：条件满足→该周期输出一次；条件不满足→该周期抑制输出。三个数据对象各自独立评估，逐周期重复执行。 |
| Rationale | SR-1 三条需求条款共同的行为模式（规则 R-04/R-05，对应原子规则 AR-10）。「每个周期」的周期时长、边界、触发机制、输出时刻 SR 未定义（AMB-01），本条不定义周期语义，仅保留「每周期条件评估」这一行为模式。 |
| Verifiability | 分析：行为模式一致性审查；测试：多周期序列场景（条件满足周期输出、不满足周期抑制），周期边界/抑制时效的具体验证依赖 AMB-01、AMB-05 消解。 |
| 关联未决项 | AMB-01、AMB-05 |
